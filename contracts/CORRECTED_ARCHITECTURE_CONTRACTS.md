## Corrected Core Schemas

### 1. ProviderReference (Fleet-Agnostic)

Replace the MCP-specific `tool_name` with a protocol-aware reference:

```python
@dataclass(frozen=True)
class ProviderReference:
    """How to invoke a capability: MCP tool, resource, prompt, or local."""
    
    protocol: Literal["mcp", "http", "local"]
    primitive: Literal["tool", "resource", "prompt"]
    name: str  # tool_name, resource_id, or local callable name
```

### 2. CapabilityProvider (Updated)

```python
@dataclass(frozen=True)
class CapabilityProvider:
    """Registry entry for a capability implementation."""
    
    # Identity
    capability_id: str                      # e.g., "organize-python-imports"
    provider_id: str                        # e.g., "rope-mcp"
    
    # How to invoke it (protocol-agnostic)
    reference: ProviderReference
    
    # Capability properties
    effect: Literal["read", "write", "admin"]
    supported_scopes: frozenset[str]
    
    # Policy
    requires_approval: bool
    supports_dry_run: bool
    supports_rollback: bool
    
    # Limits
    max_files: int | None
    timeout_seconds: int
    
    # Maturity
    status: Literal["approved", "experimental", "quarantined"]
```

**Example:**
```python
CapabilityProvider(
    capability_id="organize-python-imports",
    provider_id="rope-mcp",
    reference=ProviderReference(
        protocol="mcp",
        primitive="tool",
        name="organize_imports",
    ),
    effect="write",
    supported_scopes=frozenset({"single-python-file"}),
    requires_approval=True,
    supports_dry_run=False,
    supports_rollback=True,
    max_files=1,
    timeout_seconds=30,
    status="approved",
)
```

### 3. CapabilityRequest (Explicit, Was Missing)

```python
@dataclass(frozen=True)
class CapabilityRequest:
    """Agent's request to perform a capability."""
    
    # Identity (agent-supplied)
    run_id: str                             # Workflow identity
    capability_id: str                      # What is requested
    target: Mapping[str, object]            # What to operate on
    parameters: Mapping[str, object]        # How to operate
    preview: bool                           # Dry-run intent?
    
    # Context (agent-supplied)
    principal_id: str                       # Who is asking?
    workspace_id: str | None                # In which workspace?
    
    # Metadata
    operation_id: str = None                # Generated by fleet-ops
    requested_effect: Literal["read", "write", "admin"] = None  # Agent's declared intent
```

**Ownership:**
- Agent supplies: `capability_id`, `target`, `parameters`, `preview`, `principal_id`, `workspace_id`
- Fleet-ops generates: `run_id`, `operation_id`, `requested_effect` (if not supplied)

### 4. CapabilityDecision (Corrected State Model)

Replace the ambiguous `allowed + approval_required` boolean pair with explicit state:

```python
@dataclass(frozen=True)
class CapabilityDecision:
    """Fleet-ops decision on whether to invoke a capability."""
    
    # Request context
    run_id: str
    operation_id: str
    capability_id: str
    provider_id: str | None
    
    # Decision state (NOT a boolean pair)
    status: Literal[
        "allowed",              # Can invoke now
        "denied",               # Rejected by policy
        "pending_approval",     # Authorized, awaiting human sign-off
        "pending_lease",        # Authorized, awaiting workspace lease
    ]
    
    # Details
    reason: str                             # Why allowed/denied/pending?
    decision_source: str                    # "authorization" | "policy" | "quota"
    
    # Constraints to enforce
    constraints: Mapping[str, object]       # {"max_files": 1, "timeout_s": 30}
    
    # Approval context (if status == pending_approval)
    approval_required: bool
    approval_id: str | None = None         # Set after approval granted
    
    # Lease context (if status == pending_lease)
    lease_request_id: str | None = None
```

**Key difference:** A decision with `status="pending_approval"` MUST NOT be invokable. The MCP cannot execute until approval is granted and the decision is re-issued with `status="allowed"` and `approval_id` set.

**Example (denied):**
```python
CapabilityDecision(
    status="denied",
    reason="Principal lacks write authorization for this workspace",
    provider_id=None,
    constraints={},
)
```

**Example (pending approval):**
```python
CapabilityDecision(
    status="pending_approval",
    provider_id="rope-mcp",
    reason="Authorized, but write operations require approval",
    approval_required=True,
    constraints={"max_files": 1, "timeout_s": 30},
)
```

**Example (allowed, no approval needed):**
```python
CapabilityDecision(
    status="allowed",
    provider_id="vscode-workspace-mcp",
    reason="Read-only operation, no approval needed",
    approval_required=False,
    constraints={"max_files": 10000, "timeout_s": 60},
)
```

## Corrected Dependency & Ownership Rules

### agent-tooling (Optional, Shared Types)

**Revised:** Repositories may depend on published `agent-tooling` primitives (OperationContext, AuditEvent, audit interfaces) if they participate in governed operation and audit flows. This is NOT a universal requirement.

**Guardrails:**
1. ❌ SHALL NOT import from MCP servers or fleet-ops
2. ❌ SHALL NOT own capability routing or authorization
3. ✅ SHALL publish immutable context/audit types
4. ✅ SHALL NOT require downstream dependencies (optional exports only)

### rope-mcp & vscode-workspace-mcp (Capability Providers)

**Revised:** MCPs may implement multiple concrete capabilities (tools, resources, prompts), but must not own the fleet-wide capability registry or provider-selection policy.

**Guardrails:**
1. ❌ SHALL NOT own a capability registry
2. ❌ SHALL NOT define routing logic
3. ❌ SHALL NOT call fleet-ops or other MCPs directly
4. ✅ SHALL enforce tool-specific constraints (timeout, bounds, path validation)
5. ✅ SHALL accept OperationContext from caller and preserve run_id
6. ✅ SHALL return execution telemetry (latency_ms, result_count, etc.)

### toolboxes (Domain-Specific Capabilities)

**Revised:** Toolboxes declare what domain capabilities they provide, but do not own the mapping to providers or the routing logic.

**Guardrails:**
1. ❌ SHALL NOT import from MCP servers or fleet-ops
2. ❌ SHALL NOT own routing or provider selection
3. ❌ SHALL NOT directly invoke MCP clients
4. ✅ SHALL declare capability metadata (effect, approval requirement, domain scope)
5. ✅ SHALL be MCP-agnostic and runnable standalone

**Capability Metadata (Simplified):**
```python
@dataclass(frozen=True)
class CapabilityMetadata:
    """What a toolbox declares it can do."""
    
    name: str                                   # e.g., "todo-analysis"
    effect: Literal["read", "write", "admin"]   # Side effect level
    approval_required: bool                     # Needs human sign-off?
    prerequisites: tuple[str, ...]              # Capabilities that must run first
    
    # Do NOT include:
    # - provider_id
    # - MCP references
    # - routing logic
```

The mapping from `TodoAnalysisToolbox.metadata` to `rope-mcp` or another provider belongs entirely in `fleet-ops`.

### fleet-ops (Orchestration & Control Plane)

**Revised:** fleet-ops owns routing decisions, not provider implementations. Do not copy MCP tool implementations into fleet-ops.

**Guardrails:**
1. ✅ SHALL maintain CapabilityProvider registry
2. ✅ SHALL evaluate CapabilityRequest → CapabilityDecision
3. ✅ SHALL enforce leases, authorization, and approval gates
4. ✅ SHALL coordinate with provider transport to invoke capabilities
5. ❌ SHALL NOT implement tool logic (belongs in rope-mcp, vscode-workspace-mcp)
6. ❌ SHALL NOT assume all providers are MCP tools

**Provider Invocation Interface:**
```python
class ProviderInvoker(Protocol):
    """Abstract interface for invoking a capability via any transport."""
    
    async def invoke(
        self,
        reference: ProviderReference,
        context: OperationContext,
        arguments: Mapping[str, object],
        constraints: Mapping[str, object],
    ) -> ProviderResult:
        """Invoke a capability through its transport."""
        ...
```

Then `fleet-ops` owns the decision logic, while an adapter owns the transport:

```text
fleet-ops:
    1. Parse CapabilityRequest
    2. Authorize (check principal, policy, quota)
    3. Check approval requirement
    4. Check/acquire workspace lease
    5. Return CapabilityDecision

provider transport:
    6. Resolve provider connection (MCP, HTTP, local)
    7. Invoke with constraints and context
    8. Return result

MCP server (tool-specific):
    9. Execute tool implementation
    10. Emit provider execution events
    11. Return result to transport
```

**fleet-ops does NOT know or care how a provider is invoked.** It only knows:
- What capability was requested
- Which provider can satisfy it
- What constraints apply
- Whether approval is needed

## Corrected Audit Event Semantics

**Ownership (NOT "MCP emits, everyone else ignores"):**

```text
fleet-ops:
    - Records CapabilityRequest (request_id, principal_id, time)
    - Records CapabilityDecision (decision_id, status, provider, time)
    - Records approval (if required; approval_id, approver, time)
    - Records lease acquisition (if needed; lease_id, holder, time)
    - Records invocation start (invocation_id, decision_id, time)

MCP/Provider:
    - Emits provider execution events (tool_started, tool_completed, error)
    - Reports telemetry (latency_ms, result_count, constraints_applied)
    - Does NOT claim authorization (that's fleet-ops' job)

fleet-ops (final):
    - Records invocation result (success/failure, result_id)
    - Correlates full trace: request → decision → approval → lease → invocation → result
    - Emits unified AuditEvent or publishes to audit sink
```

**Contract:**

MCP servers may emit provider-level events to an agent-tooling AuditSink IF the sink interface is defined and optional. Do not require MCPs to export audit events as a contract requirement.

Simpler approach: MCPs return telemetry in the result; fleet-ops coordinates the audit trail.

## Corrected Scanner & Baseline Strategy

### Phase 1: Executable, Minimal Scanner

The scanner should start small and reliable:

```python
#!/usr/bin/env python3
"""Boundary compliance scanner (minimal version).

Checks:
  - Import boundaries (AST-based)
  - Required boundary-file existence
  - Schema ownership (type introspection)
  - Exception expiry
  - Baseline/new-finding comparison

Does NOT check:
  - String-based function name heuristics
  - Vocabulary compliance (too subjective)
  - Code organization patterns
"""

import ast
import json
import sys
from pathlib import Path
from dataclasses import dataclass, asdict
from datetime import datetime, timezone

@dataclass
class BoundaryFinding:
    rule_id: str
    repository: str
    path: str
    line: int | None
    fingerprint: str  # for baseline matching
    severity: str  # "error", "warning"
    message: str

def scan_import_boundaries(repo_path: Path, forbidden_imports: set[str]) -> list[BoundaryFinding]:
    """AST-based import boundary checking."""
    findings = []
    
    for py_file in repo_path.rglob("*.py"):
        if "test" in str(py_file):  # Skip tests for now
            continue
        
        try:
            with open(py_file) as f:
                tree = ast.parse(f.read(), filename=str(py_file))
        except SyntaxError:
            continue
        
        for node in ast.walk(tree):
            if isinstance(node, ast.ImportFrom):
                module = node.module or ""
                if any(module.startswith(fb) for fb in forbidden_imports):
                    findings.append(BoundaryFinding(
                        rule_id="BOUNDARY-002",
                        repository=repo_path.name,
                        path=str(py_file),
                        line=node.lineno,
                        fingerprint=f"{py_file}:{node.lineno}:{module}",
                        severity="error",
                        message=f"Forbidden import: {module}",
                    ))
            elif isinstance(node, ast.Import):
                for alias in node.names:
                    if any(alias.name.startswith(fb) for fb in forbidden_imports):
                        findings.append(BoundaryFinding(
                            rule_id="BOUNDARY-002",
                            repository=repo_path.name,
                            path=str(py_file),
                            line=node.lineno,
                            fingerprint=f"{py_file}:{node.lineno}:{alias.name}",
                            severity="error",
                            message=f"Forbidden import: {alias.name}",
                        ))
    
    return findings

def check_schema_ownership(repo_path: Path, expected_exports: dict[str, str]) -> list[BoundaryFinding]:
    """Verify required schemas are defined in expected repositories."""
    findings = []
    
    for export_name, expected_module_prefix in expected_exports.items():
        try:
            module_path = repo_path / expected_module_prefix.replace(".", "/")
            # Check if module exists and defines the export
            # (simplified; real implementation uses importlib)
            if not (module_path / "__init__.py").exists():
                findings.append(BoundaryFinding(
                    rule_id="BOUNDARY-003",  # or BOUNDARY-004
                    repository=repo_path.name,
                    path=str(module_path),
                    line=None,
                    fingerprint=f"{repo_path.name}:{export_name}",
                    severity="error",
                    message=f"Missing schema: {export_name} in {expected_module_prefix}",
                ))
        except Exception:
            pass
    
    return findings

def load_baseline(baseline_path: Path) -> set[str]:
    """Load fingerprints of pre-existing findings."""
    if not baseline_path.exists():
        return set()
    
    with open(baseline_path) as f:
        baseline = json.load(f)
    
    return {finding["fingerprint"] for finding in baseline}

def check_exception_expiry(exceptions: list[dict]) -> list[BoundaryFinding]:
    """Verify exceptions are not expired."""
    findings = []
    now = datetime.now(timezone.utc)
    
    for exc in exceptions:
        expires = datetime.fromisoformat(exc["expires"]).replace(tzinfo=timezone.utc)
        if expires < now:
            findings.append(BoundaryFinding(
                rule_id=exc["rule_id"],
                repository=exc["repository"],
                path=exc["scope"][0] if isinstance(exc["scope"], list) else exc["scope"],
                line=None,
                fingerprint=f"{exc['id']}:expired",
                severity="warning",
                message=f"Exception {exc['id']} expired on {exc['expires']}. Replacement plan: {exc['replacement_plan']}",
            ))
    
    return findings

def main():
    import argparse
    
    parser = argparse.ArgumentParser()
    parser.add_argument("--mode", choices=["report", "strict"], default="report")
    parser.add_argument("--baseline", type=Path, default=Path("boundary-baseline.json"))
    args = parser.parse_args()
    
    # Load configuration
    with open("repository-manifest.yaml") as f:
        import yaml
        manifest = yaml.safe_load(f)
    
    all_findings = []
    
    # Run checks for each repository
    for repo_name, repo_config in manifest["repositories"].items():
        repo_path = Path(f"../{repo_name}")  # Adjust for your layout
        if not repo_path.exists():
            print(f"⚠ Repository not found: {repo_path}")
            continue
        
        # Import boundaries
        for rule_id, rule in manifest["rules"].items():
            if rule["check_type"] == "import_boundary" and repo_name in rule["repos"]:
                forbidden = [r for r in manifest.get("forbidden_imports", {}).get(repo_name, [])]
                findings = scan_import_boundaries(repo_path, set(forbidden))
                all_findings.extend(findings)
        
        # Schema ownership
        for rule_id, rule in manifest["rules"].items():
            if rule["check_type"] == "schema_ownership" and repo_name in rule["repos"]:
                expected = manifest.get("expected_schemas", {}).get(repo_name, {})
                findings = check_schema_ownership(repo_path, expected)
                all_findings.extend(findings)
    
    # Check exception expiry
    findings = check_exception_expiry(manifest.get("exceptions", []))
    all_findings.extend(findings)
    
    # Filter baseline
    baseline = load_baseline(args.baseline)
    new_findings = [f for f in all_findings if f.fingerprint not in baseline]
    
    # Report
    print(f"\n{len(all_findings)} total findings ({len(new_findings)} new)")
    for finding in new_findings:
        print(f"  {finding.rule_id} ({finding.repository}:{finding.line}): {finding.message}")
    
    if args.mode == "strict" and new_findings:
        print(f"\n❌ Strict mode: {len(new_findings)} new violations block merge")
        sys.exit(1)
    else:
        print(f"\n✓ Report-only mode: baseline updated")
        sys.exit(0)

if __name__ == "__main__":
    main()
```

Key differences from pseudocode:
- AST-based import detection (no false positives from comments/strings)
- Fingerprinted findings for baseline tracking
- Timezone-aware exception expiry
- Separate "new finding" vs "baseline finding" logic
- Minimal rule set (expands only after proving accuracy)
